# AI Pages — инструкции для агентов

Витрина самодостаточных приложений: каждый `*.html` в корне — отдельное приложение, сборки нет; `index.html` — каталог.

Документация и сообщения в чате — на русском языке.

`npm test` сам поднимает сервер на :5500; `npm run serve` нужен, только чтобы открыть страницы в браузере или Playwright
MCP.

Pre-commit хук (Husky + lint-staged) форматирует и линтит staged-файлы. Хук упал — коммита нет: исправь причину и создай
новый коммит. Проверки проходи, а не обходи: `--no-verify` запрещён.

## Куда смотреть

- **Код** или HTML-приложение правишь — сначала прочитай `CODING_STANDARDS.md`, перед завершением задачи пройди его
  чек-лист.
- **CI/CD**, деплой, архитектура — `docs/ARCHITECTURE.md`.
- **Требования** к продукту — `docs/PRD_AI_PAGES.md`.
