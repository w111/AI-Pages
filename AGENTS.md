# AI Pages — инструкции для агентов

AI Pages — витрина самодостаточных одностраничных приложений: каждый `*.html` в корне — отдельное приложение со
встроенными CSS и JS, библиотеки подключаются через CDN, сборки нет. `index.html` — главная страница-каталог. Тесты —
pytest и Playwright.

Документация и сообщения в чате — на русском языке. Независимые подзадачи делегируй субагентам.

## Команды

```bash
npm run serve        # статический сервер на http://127.0.0.1:5500
npm test             # pytest, затем Playwright (Playwright сам поднимает сервер на :5500)
npm run test:python  # только pytest
npm run test:js      # только Playwright; один файл: npx playwright test test_js/<файл>.spec.js
npm run lint         # все линтеры
```

Python запускай через `python3`.

## Коммиты

Pre-commit хук (Husky + lint-staged, правила — `package.json` → `lint-staged`) форматирует и линтит staged-файлы. Хук
упал — коммит не создан: исправь причину и создай новый коммит. Проверки проходи, а не обходи: `--no-verify` запрещён.

## Куда смотреть

- **Код** или HTML-приложение правишь — сначала прочитай `CODING_STANDARDS.md`, перед завершением задачи пройди его
  чек-лист.
- **Архитектура**, CI/CD, CDN-зависимости, деплой — `docs/ARCHITECTURE.md`.
- **Требования** к продукту и приложениям — `docs/PRD_AI_PAGES.md`.
- **Внешние данные** нужны приложению — выбери бесплатный API в каталоге <https://github.com/public-apis/public-apis>.
