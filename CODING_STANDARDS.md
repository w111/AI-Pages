# Стандарты кода

## Стиль

- `*.html` не проверяют ни Prettier, ни ESLint: встроенные CSS и JS форматируй в стиле окружающего файла.
- Комментарии, названия тестов и сообщения проверок — на русском.
- Комментируй функции, классы, методы и неочевидную логику; JS-функции — JSDoc с тегами `@function`, `@description`,
  `@param`, `@returns`.

## HTML-приложение

- Вверху файла — HTML-комментарий с техническим заданием приложения (образец — `snake.html`).
- Один файл — одно приложение: CSS и JS встроены, vanilla JS без фреймворков. Библиотеки — с CDN с фиксированной версией
  из `docs/ARCHITECTURE.md` → CDN Dependencies Registry; 3D — Three.js, физика — Cannon.js.
- Иконки в приложениях — Font Awesome (`index.html` использует Lucide).
- Переключатели (тема, язык) — `label.toggle-switch` с `span.slider`, как в `index.html`. Пункт настроек —
  `.settings-option` с `label` и toggle-switch (шаблон — `docs/ARCHITECTURE.md` → Стандартная система тем).
- Внешние данные — бесплатный API из каталога <https://github.com/public-apis/public-apis>.
- Новое приложение добавь в каталог: объект в массиве `tools` в `index.html` (`category` — `id` из массива `categories`)
  и скриншот `screenshots/<имя>.png` для поля `preview`.

## Временные файлы

Одноразовые скрипты, скриншоты и логи создавай в scratchpad или `/tmp`; попавшие в репозиторий удали до завершения
задачи.

## Перед завершением задачи

Задача меняет поведение для пользователя — задача готова, когда пройдены все четыре пункта:

1. **Ревью**: независимый субагент критически проверил решение, критические находки исправлены.
2. **Линт**: `npm run lint` проходит без ошибок.
3. **Тесты**: на новую функциональность есть тест, `npm test` зелёный.
4. **UI**: основные пользовательские пути проверены через Playwright MCP.
